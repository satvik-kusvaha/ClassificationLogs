# 🤖 AI-Powered Log Classification System

An end-to-end log classification platform that automatically categorizes system and application logs using a hybrid artificial intelligence pipeline. Built with **FastAPI**, **BERT embeddings**, **machine learning**, **Large Language Models (LLMs)**, and **regex-based pattern matching**, the application intelligently processes structured and unstructured log data uploaded through a REST API.

The system combines multiple classification techniques to maximize both accuracy and scalability, returning a processed CSV containing predicted classifications for each log entry.

---

## Overview

System logs are generated by virtually every modern application, but manually categorizing thousands of log entries is time-consuming and error-prone. This project automates that process by combining traditional rule-based techniques with modern NLP and machine learning models.

Rather than relying on a single classifier, the application routes logs through multiple AI-driven classification methods depending on their complexity. Structured logs are efficiently matched using regex patterns, semantically rich logs are classified using BERT embeddings and Logistic Regression, and ambiguous or legacy-system logs are handled through an LLM-powered fallback classifier.

## Hybrid Classification Pipeline

The platform intelligently selects the most appropriate classification strategy based on each log message.

### 1. Regex Classification
- Fast rule-based matching
- Ideal for repetitive and structured logs
- Low computational cost

### 2. BERT Semantic Classification
- Generates contextual text embeddings
- Logistic Regression predicts log categories
- Handles more complex language patterns

### 3. LLM Fallback Classification
- Processes ambiguous or previously unseen logs
- Provides contextual reasoning
- Supports legacy system log interpretation

This layered architecture balances speed, scalability, and classification accuracy.

## Workflow

1. User uploads a CSV containing log messages.
2. The system validates the uploaded file.
3. Logs are processed through the hybrid classification pipeline.
4. Structured logs are matched using regex patterns.
5. Complex logs are classified using BERT embeddings and Logistic Regression.
6. Ambiguous or legacy logs are routed to an LLM for contextual classification.
7. Classified results are exported as a processed CSV.
8. Users download the completed dataset through the API.
